# Upgrading to v1.11.0

`@a-novel-kit/nodelib-test` drops its `./msw` entry, which no repository imported. The package no
longer asks for `msw` as a peer or depends on `lodash-es`.

## Do I need to act?

**Only if you import `@a-novel-kit/nodelib-test/msw`.** Every other consumer upgrades without a
change and stops seeing the unmet `msw` peer warning. The `./http` and `./playwright` entries are
unchanged.

## Replace the MSW helpers

Mock HTTP at the boundary your tests already own: inject a client interface into the code under
test, or run the suite against the real service. A test that still needs request interception
can depend on `msw` directly.
