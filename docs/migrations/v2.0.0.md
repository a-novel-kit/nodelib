# Upgrading to v2.0.0

`@a-novel-kit/nodelib-config` moves its Svelte and Storybook lint rules to their own entry point, so
a TypeScript package no longer installs those lint plugins. `HttpError` from
`@a-novel-kit/nodelib-browser/http` exposes its status and tags as plain fields.

## Do I need to act?

**Required** for a package whose ESLint config passes `svelte`, `storybook` or `isLib` to `Eslint()`,
and for a subclass of `HttpError` that overrides `status` or `tags`. **Recommended** for a package that
installs `eslint-plugin-svelte` or `eslint-plugin-storybook` only for the shared config. Code that
reads `status` or `tags` is unchanged.

## Import the Svelte lint config from `nodelib-config/eslint-svelte`

`Eslint()` lints TypeScript and drops its `svelte`, `storybook` and `isLib` options. `EslintSvelte()`
from `@a-novel-kit/nodelib-config/eslint-svelte` takes every `Eslint()` option plus those three, and
builds the config `Eslint()` built from them in 1.x. Its `svelte` option is required.

`EslintSvelte()` loads both lint plugins, which become optional peers. A package that imports it
installs `eslint-plugin-svelte` and `eslint-plugin-storybook` itself, even without `storybook: true`.

uikit switches the import and the call, then adds `eslint-plugin-storybook` to its
`devDependencies`, which list only `eslint-plugin-svelte` today:

```diff
-import { Eslint } from "@a-novel-kit/nodelib-config";
+import { EslintSvelte } from "@a-novel-kit/nodelib-config/eslint-svelte";

-export default Eslint({ svelte: {}, isLib: true, gitIgnorePath: import.meta.dirname + "/.gitignore" });
+export default EslintSvelte({ svelte: {}, isLib: true, gitIgnorePath: import.meta.dirname + "/.gitignore" });
```

platform-studio and platform-template already pin both plugins. Each switches the import and the
call, and keeps its options and any extra rules block:

```diff
-import { Eslint } from "@a-novel-kit/nodelib-config";
+import { EslintSvelte } from "@a-novel-kit/nodelib-config/eslint-svelte";

 export default defineConfig(
-  ...Eslint({
+  ...EslintSvelte({
     gitIgnorePath: path.join(import.meta.dirname, ".gitignore"),
     ignores: ["src/lib/i18n/generated/**"],
     storybook: true,
     svelte: {},
   })
 );
```

`eslint --print-config` prints the same config for a `.svelte` file before and after the switch.

## Drop the unused lint plugins

A package that only calls `Eslint()`, such as a service, removes `eslint-plugin-svelte` and
`eslint-plugin-storybook` from its `devDependencies` unless its own config imports them.

## Read `HttpError` fields directly

`status` and `tags` are public `readonly` fields. A subclass that overrides either getter declares a
field instead, since TypeScript rejects an accessor that overrides a property. `JSON.stringify` and
object spread now include both fields, so a serialized `HttpError` carries its status and tags.
